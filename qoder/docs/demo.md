# 演示说明

## 项目演示流程

### 第一步：启动与概览

1. 启动应用后访问首页
2. 查看仪表盘，确认 PowerContext 和 seekdb 连接状态
3. 点击"加载示例数据"，导入 5 条学习资料

### 第二步：知识库管理

1. 进入"知识库"页面
2. 手动添加一条学习资料：
   - 标题：动态规划算法
   - 学科：算法设计
   - 主题：动态规划
   - 内容：动态规划通过将问题分解为重叠子问题...
3. 确认资料保存成功

### 第三步：智能检索（seekdb 发挥作用）

1. 进入"智能检索"页面
2. 搜索"数据库存储"
3. 观察混合检索结果：
   - 向量语义匹配：找到"向量检索与语义搜索"
   - 关键词匹配：找到"数据库索引原理"
4. 切换不同检索模式对比效果

### 第四步：学习进度追踪（PowerContext 发挥作用）

1. 进入"学习进度"页面
2. 记录进度：Python编程 > 列表推导式 > 80%
3. 记录薄弱点：机器学习 > 反向传播 > 梯度消失问题理解不深
4. 刷新查看学习记录

### 第五步：智能问答

1. 进入"智能问答"页面
2. 提问："数据库索引有哪些类型？"
3. 观察回答：
   - 引用 seekdb 检索到的知识资料
   - 结合 PowerContext 中的学习记录
   - 显示检索来源统计

### 第六步：会话连续性（PowerContext Handoff）

1. 开始一个新的学习会话
2. 进行一些学习和搜索操作
3. 结束会话
4. 重新开始，观察系统是否能召回之前的上下文

## 技术验证要点

### PowerContext 验证
- 查看 PowerContext Server 日志，确认 Memory 写入/召回记录
- 验证 Experience 记录（每次操作都会生成经验记录）
- 验证 Handoff 记录（学习会话开始/结束时创建）
- 验证 Scope 隔离（不同 scope_id 的数据互不干扰）

### seekdb 验证
- 查看 seekdb 中的 Collection 和 Namespace
- 验证向量索引的创建（IVF 配置）
- 验证全文索引的创建（IK 分词器）
- 对比混合检索 vs 纯关键词检索的效果差异
