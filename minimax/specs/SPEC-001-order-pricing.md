# SPEC-001 计价规则

> 版本：v1.2 ｜ 状态：生效 ｜ 负责人：交易域 ｜ 最后更新：2026-09-30

## 1.1 金额口径

所有金额以「分」为单位的整数存储与传递，禁止在业务代码里使用浮点数表示金额。
前端展示时才除以 100 并保留两位小数。

## 1.2 会员折扣

会员折扣按商品金额合计计算，使用 `money.apply_rate` 以 HALF_UP 取整到分：

| 会员等级 | 折扣率 |
| --- | --- |
| none | 0% |
| silver | 3% |
| gold | 8% |

折扣率变更属于运营配置变更，需要同步更新 `pricing.MEMBER_DISCOUNT_RATES` 与本文档。

## 1.3 优惠券

优惠券在会员折扣之后抵扣，抵扣上限为「商品金额 − 会员折扣」。
优惠券不找零、不叠加、不参与运费计算；一单只能使用一张优惠券。

## 1.4 结算顺序

结算顺序固定为：商品金额合计 → 会员折扣 → 优惠券 → 运费 → 实付金额。
任何一步的顺序调整都会改变运费门槛的判定结果，属于破坏性变更，必须走规格评审。

## 1.5 舍入

所有取整一律 HALF_UP（四舍五入），由 `ordercore.money` 统一实现。
禁止在调用点各自实现 `round()`，因为 Python 内置 `round` 是银行家舍入。
