# 高德赛道 · 周边去哪儿（Nearby Explore Skill）

赛题：**周边去哪儿：基于高德的地点推荐助手**（高德开放平台 MCP Server，总分 20）。

本目录就是该赛题的提交产物：一个 Skill 文件 **[`SKILL.md`](SKILL.md)**。

## 交付物

| 文件 | 说明 |
|---|---|
| `SKILL.md` | 唯一提交产物。描述「提出需求 → 查询高德 → 返回推荐」的完整任务流程：需求解析、周边搜索、步行路线核验、筛选排序、回答格式、异常降级 |

不含源码、测试脚本、演示视频；不含任何 API Key（运行环境与高德密钥由评测平台统一配置）。

## 设计要点（与评分维度对齐）

| 维度 | 权重 | 对应做法 |
|---|---|---|
| 数据真实性 | 40% | 名称/地址逐字取用 POI 返回字段；步行距离与时间只取 `maps_direction_walking` 的 `paths[0].distance`（米）/ `duration`（秒），明确禁止把周边搜索的直线距离 `pois[].distance` 当步行距离 |
| 需求满足 | 30% | 步行时间上限按硬约束处理（超时地点不入表，只报数量）；推荐数量硬上限 3 家，不足如实说明 |
| 推荐合理性 | 20% | 直线距离初筛前 6 家 → 逐家步行核验 → 按步行时间升序 → 推荐理由只引用本轮的路线数据；无结果/服务异常有明确的降级路径，不编造 |
| 表达清晰度 | 10% | 先一句结论，再 5 列表格（地点/地址/距离/时间/理由），表下 1–3 句说明数量不足、未核实项或异常原因 |

## 关键取舍

- **半径估算**：步行路线通常比直线距离长 1.2–1.4 倍，首轮搜索半径取 `ceil(时间上限 × 70)` 米（15 分钟 → 1050 m），避免"半径够但步行超时"的空筛。
- **调用预算**：1 次周边搜索（必要时补搜 1 次）+ 最多 6 次步行规划，整轮 ≤ 8 次工具调用，防止平台侧超时。
- **不猜属性**：评分、人均、营业状态、排队、安静程度高德 MCP 均不返回，一律标「未核实」，避免 AI 评审认定为无依据描述。

## 本地自测方式

Skill 由评测平台加载执行，本仓库不附测试脚本。如需人工核对流程，可用任意支持 MCP 的客户端接入高德 MCP Server
（见 <https://developer.amap.com/api/mcp-server/summary>），把 `SKILL.md` 作为技能加载后给一句话需求即可。
